# Конвейер монтажа коротких роликов (Reels / Shorts / TikTok)

Конвейер, на котором монтируются ролики личного бренда Влада. Монтажёра нет: всё делает Claude, человек только утверждает результат на трёх контрольных точках. Тяжёлая работа (расшифровка, рез, рендер) идёт на Маке через «мост», Claude даёт ему задания и проверяет результат.

Передаётся Вове для товарного проекта со световыми артами: у него уже есть аккаунты, автовыкладка и уникализация — этот репозиторий закрывает этап **монтажа**.

```
съёмка → [ЭТОТ КОНВЕЙЕР: разбор → черновик → монтажный лист → полный монтаж → чистовик] → уникализация → автовыкладка → трафик на WB
```

## Установка (Mac на Apple Silicon)

1. Скачать репозиторий и положить папку туда, где будут жить проекты (лучше **не** в iCloud Desktop — iCloud тормозит работу с большими файлами).
2. `pipeline/bridge/Установить мост.command` — двойной клик. Ставит Python-среду в `~/Library/Application Support/MAOS-bridge/` (вне папки проекта), зависимости, **скачивает модель GigaAM** и делает самопроверку.
   Если macOS не даёт запустить — правый клик → Открыть, или `chmod +x pipeline/bridge/*.command pipeline/bridge/*.sh`.
3. Remotion (графика): `bash pipeline/bridge/setup_remotion.sh` — Node 22 + Remotion 4.0.529 + браузер для рендера.
4. HyperFrames (по желанию): `bash pipeline/bridge/setup_hyperframes.sh`.
5. Запуск перед каждой сессией монтажа: `pipeline/bridge/Запустить мост.command` — окно держать открытым.
6. Проверка: в `pipeline/bridge/heartbeat.json` поле `alive` обновляется каждые несколько секунд.

Если модель не скачалась (нет доступа к Hugging Face) — положить файлы `v3_rnnt_*.onnx` в `pipeline/models/gigaam/` из полного zip-архива, который передаётся отдельно.

## Подключение к Claude

1. **Навык:** в Claude → Settings → Capabilities → Skills загрузить папку `skills/montazh-rolika` (или zip из неё). Лучше сразу сделать свою копию под товарный проект (см. ниже).
2. **Проект:** создать проект в Claude и добавить в него документы из `docs/` — навык ссылается на них при старте каждого чата.
3. **Связь с Маком:** в Claude desktop подключить папку с этим репозиторием к чату — тогда Claude сможет давать задания мосту и забирать результат.
4. Один ролик = один чат. Первое сообщение: «Монтируем ролик <тема>, исходник <файл>, сценарий <где>».

## Что надо поменять под товарный проект (световые арты)

Конвейер собран под **говорящую голову** Влада. Для товарного контента большая часть работает как есть (рез, звук, цвет, субтитры, графика Remotion, музыка/SFX, проверки, процесс утверждений), но несколько вещей завязаны на Влада:

**Пути и железо** (в `SKILL.md`, `docs/Монтаж — правила и конвейер.md`, `config.json → paths`):
- `/Users/vladislavugolnikov/Desktop/Личный бренд/Продакшн/pipeline` → свой путь к `pipeline`.
- Исходники на SSD `/Volumes/T7 Shield/` (Blackmagic Camera + прокси) → свой диск/папку с исходниками. Если прокси нет — `montage.py` использует исходник.

**Бренд и стиль** (`config.json`):
- `lower_third` — плашка «Влад Угольников · основатель ZUBRO» → свой бренд или убрать.
- `subtitles.accent_words` — слова для красного акцента (сейчас про селлеров/маржу) → слова своей ниши (свет, арт, подарок, интерьер…).
- `subtitles.censor_words` — запрещённые для рекламы слова (р*бли, бесплатн*, ст*ит, подп*ска) — **оставить**, это требования площадок.
- `service_phrases` — фразы «хороший дубль» и т.п., которые вырезаются из речи.
- `hook`, `colorgrade`, `voice.chain` — под свою съёмку. Для светящихся артов в темноте цветокор нужно подбирать заново (текущий убирает розовый оттенок кожи).
- Дизайн-код (Oswald капс + красный акцент `#e60f13`) — в `docs/notes/Визуальный язык и пайплайн.md` и `remotion/src/Reel.tsx`. Для световых артов, скорее всего, нужна своя палитра.

**Формат роликов:**
- Если в ролике есть человек в кадре — всё работает сразу (кадрирование по лицу, разбор дублей по взгляду).
- Если это **продуктовые кадры без лица** (арт крупно, распаковка, интерьер) — лицо не найдётся, и кадр строится по центру. Для таких роликов логика другая: закадровый голос/музыка → подложка из продуктовых клипов (`broll` в плане base) → графика Remotion. Пример именно товарного ролика — `docs/notes/Алкотур - видеорендеры.md`.
- Хуки: формулы в `docs/Хуки и удержание — метод.md` собраны по нише селлеров — формулы пересобрать по своей нише тем же методом (`bridge/refs.py`, режимы `raw` → `dl` → `hooks`), правила кадра 0 и A/B-процесс переносятся как есть.

**Удобно так:** открыть чат с Claude, подключить эту папку и попросить: «Прочитай README и SKILL.md, адаптируй навык и config.json под товарный проект <описание>, предложи свою копию навыка». Claude сделает адаптированную версию навыка и настроек.

**Сбор референсов через Apify** (`bridge/refs.py`) — нужен свой ключ Apify: положить JSON со строкой ключа в файл `pipeline/bridge/Ключ Apify.json`. Файл в `.gitignore`, в репозиторий не попадает.
