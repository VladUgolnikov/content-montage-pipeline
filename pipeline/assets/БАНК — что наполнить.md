# Банк материалов для монтажа — что наполнить

## Постоянный банк (pipeline/assets/ — живёт между роликами)
| Папка | Что кладём | Статус |
|---|---|---|
| fonts/ | 3 шрифта: заголовочный (Oswald700 ✅ есть), субтитровый, рукописный (акцентное слово в хуке) | нужен субтитровый + рукописный |
| stickers/ | брендовая PNG-иконка без фона (вотемарк на весь ролик) | нужно |
| music/ | фоновые треки mp3 (royalty-free), 5–10 шт | нужно |
| sfx/ | короткие звуки появления вставок (whoosh/pop) | нужно |
| context_assets/ | постоянные вставки: лого MAOS, скрины продукта, повторяющиеся мемы | нужно |
| library/ | шаблон: полоса сверху, градиент снизу | сделаю сам |
| presets/ | LUT/цветокор, стили | сделаю сам |

## Рабочие папки (на каждый ролик, шаблон в reels/)
input/ (сырьё) · inserts/ (вставки этого ролика) · output/ (готовое) · done/ (использованное)

## Приоритет наполнения
1. Субтитровый + рукописный шрифт
2. Бренд-стикер (иконка)
3. 5–10 музыкальных треков
4. Пачка sfx
5. context_assets (лого MAOS, скрины продукта)

## Чем закрыть пробелы
- Музыка, sfx, моушн-графика, генерация вставок → **ChatCut** (плагин, генерит ассеты).
- B-roll → твой банк подсъёмов (177 клипов уже есть).
- Шрифты/стикер/лого → твоё/дизайнер (фирменное, некопируемое).
