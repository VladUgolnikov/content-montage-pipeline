## 1. Пути и окружение

- Mac (для device_* инструментов): `/Users/vladislavugolnikov/Desktop/Личный бренд/Продакшн/pipeline` (папка в iCloud).
- В `device_bash` путь с кириллицей хранится в NFD — строй так:

- Исходники: SSD **`/Volumes/T7 Shield/`** (Blackmagic Camera: `A001_<дата>_C0NN.mov`, прокси в `Proxy/` с тем же именем). В `device_bash` T7 часто не смонтирован — это нормально, мост читает его сам. Исходники не копировать.
- Локальные среды (вне iCloud): `~/Library/Application Support/MAOS-bridge/` → `venv` (Python 3.12), `node` (22), `remotion` (4.0.529 + браузер), `hyperframes` (CLI), `bin/ffmpeg|ffprobe`.
- Облачный контейнер (твоя среда): нет доступа к диску Мака напрямую; файлы туда-обратно — `device_stage_files` (в `/mnt/user-data/uploads/...`, ищи через `find ... -print0 | xargs -0`) и `device_commit_files` (из `/mnt/user-data/outputs/...`). В облаке 2 ядра — рендерить только кадры-проверки, не ролики.

### Правила работы с файлами Мака
- Загрузка через `device_commit_files` **кэшируется по имени**: новую версию файла коммить под уникальным именем в `pipeline/_archive/_in_<имя>_vN`, затем в `device_bash`: `cat _archive/_in_x > путь/x` и сверь `md5sum` с облачной копией.
- Удаление: в начале сессии запроси право удаления для корня `Личный бренд` (`device_request_delete_permission`, путь в NFD — «й» = «и» + U+0306, иначе ответ «не корень»). После `cat` + md5 сразу удаляй `_archive/_in_*`.
- `bridge/Ключ Apify.json` не открывать и не выводить (ключ читает только `bridge/refs.py`).
- В папке могли работать другие чаты: перед правкой `montage.py`/`config.json` проверь md5/дату и не затирай чужое без причины.

## 2. Мост: как давать задания

Кладёшь JSON в `pipeline/bridge/jobs/<NN_имя>.json` (через `printf '%s' '{...}' > x.tmp && mv x.tmp NN_имя.json`), смотришь `bridge/logs/<NN_имя>.log`, итог — `bridge/done/<NN_имя>.result.json`. Исполнитель (`bridge/runner.py`) сам перезапускается при обновлении и выполняет только белый список:

- `{"kind":"montage","args":{"src":"/Volumes/T7 Shield/X.mov","name":"N","transcribe_only":true}}`
- `{"kind":"montage","args":{"src":"...","name":"N","plan":"plans/N_xxx.json","words":"reels/output/N_words.json"}}` — режим берётся из `plan.mode`
- `{"kind":"py","script":"bridge/avcheck.py","args":["/Volumes/T7 Shield"]}` — fps, старт звука/видео, дрейф по всем файлам
- `{"kind":"py","script":"bridge/diag.py","args":[SRC,"старт_с","длит_с"]}` — спектр звука сырого и после шумодава
- `{"kind":"sh","script":"bridge/render_remotion.sh","args":[props, out, "draft"|"final", base, "Reel"|"Cartoon"]}` — рендер Remotion поверх базы + автосверка синхрона (`remotion/sync_fix.py`)
- ещё: `bridge/selftest.py`, `bridge/lipsync.py` (ненадёжен — не опираться), `bridge/refs.py` (Apify), `bridge/fetch_assets.py`, `bridge/setup_*.sh`, `remotion/sync_fix.py`, `cut.py`
- Новый скрипт → добавь в `PY_OK`/`SH_OK` в `bridge/runner.py` (через `_archive/_in_runner_vN.py` + `cat`).

**Ожидание:** один `sleep N` на весь ожидаемый срок задания (расшифровка 15 мин ≈ 2 мин; база 1 мин ролика ≈ 100 с; Remotion 1080p ≈ 100 с), затем один раз прочитать хвост лога. Не опрашивать каждые 20 с.

## 3. Инструменты конвейера

- `montage.py` (режимы): `transcribe_only` → `reels/output/N_words.json` + `N_transcript.txt` (GigaAM v3, пословно, только русский); `review` (`takes:[{id,lo,hi}]`) → листы лиц `N_review_*.jpg` (8 кадров на дубль) + `N_review.json` (yaw/pitch, «звук без слов», повторы); `base` (`edl:[[lo,hi],...]`, `replace`, `broll`, `graphics` с якорями) → `N_base.mp4` (рез по кадрам, кадр по лицу, джамп-зумы, цвет, голос, ×1.3) + `N_timeline.json` (слова и якоря в финальном времени, `cuts`, `broll`) + листы склеек `N_cuts_*.jpg` + лог синхрона по фрагментам. Якоря: `"слово"` — префикс, `"=слово"` — точно, `"слово#2"` — второе вхождение (осторожно: «сто» ловит «стоили»).
- `remotion/build_props.py timeline gfx out` — сценарий графики (`plans/N_gfx.json`, ссылки `@id`, `@id:end+0.5`, `@cutN`, `@dur`) → props для Remotion. Субтитры строит сам (группировка по паузам/склейкам, акцент — красный бокс).
- `remotion/src/Reel.tsx` — блоки по дизайн-коду: `chip`, `lower`, `bars`, `bignum`, `checklist`, `endcard`, `spot` + субтитры. `Cartoon.tsx` — мультсцены «бумажная аппликация» (проба).
- `assets/hyperframes/` — HeyGen HyperFrames (Apache 2.0): `registry/blocks` (165), `registry/components` (224, 30+ стилей субтитров), `skills/` (инструкции: `talking-head-recut`, `embedded-captions`, `motion-graphics`, `hyperframes-*`). Перед использованием блока прочитай его HTML и соответствующий SKILL.md. Рендер HF через мост ещё не подключён — сделай `bridge/render_hf.sh` (PATH: `MAOS-bridge/node/bin` + `MAOS-bridge/bin`, `npx hyperframes render`) и добавь в белый список.
- Ассеты: шрифты `fonts/Oswald700.ttf`, `assets/fonts/*.ttf`, `assets/fonts/google/<семья>/` (12 OFL с кириллицей); звуки `assets/sfx/kenney/<пак>/` (CC0); музыка `assets/music/` (пусто — под ролик ищем по листу).
- Примеры планов: base — `pipeline/plans/C095_m1.json` (с `a_start`, `av_offset`, `cfr30`, `colorgrade`, `voice_chain`), графика — `Ролики/2026-09-28_Манифест/plans/C095_v5_gfx.json`. Копируй структуру.

## 4. Порядок работы — 5 этапов, 3 точки утверждения

### Этап 1. Разбор записи (без Влада)
1. `avcheck` по файлу: fps (камера пишет ~30.02), старт звука, длина видео vs звука. Длинные дубли (>5 мин) дают дрейф и сдвиг (манифест C086: +0.40 с на старте, +2.3 с к концу). Если расхождение >40 мс — выравнивай звук (хлопок в начале дубля: пик звука + пик движения; при дрейфе — растяжка звука под длину видео). Скрипта для хлопка пока нет — напиши его.
2. `diag` на 30 с речи: если выше ~12 кГц пусто — предупреди Влада (микрофон закрыт одеждой / не тот вход).
3. `transcribe_only` → расшифровка. Группируй повторы фраз, помечай «хороший дубль».
4. `review` по всем дублям → посмотри листы лиц: взгляд в камеру до конца фразы, запинки, «звук без слов».
5. Собери **итоговый текст** из лучших дублей (Влад меняет текст на съёмке — дальше работаем по сказанному, не по сценарию) и таблицу «фраза → дубль → почему → альтернатива». Запиши в `status.md`.

### Этап 2. Черновик 1 — чистое видео → **утверждение №1**
1. План `mode: base`: edl только между фразами, без склеек внутри фразы из разных дублей; паузы >0.4 с режутся, окончания не режутся.
2. Цвет: выравнивание между дублями + фирменный LUT (`lut3d=file.cube` в `config.colorgrade`). LUT ещё не выбран — при первом ролике покажи 2–3 варианта на одном кадре, выбранный сохрани в `assets/luts/` и в config. Текущая база: убран розовый оттенок кожи.
3. Звук: **заменить** в `config.voice.chain` жёсткий `afftdn=nr=18` на мягкое: `highpass=f=80,afftdn=nr=7:nf=-50,deesser,equalizer=f=3500:t=q:w=1:g=2,acompressor=threshold=-20dB:ratio=3,loudnorm=I=-14:TP=-1.5:LRA=11` (проверь `diag`, что 1–5 кГц не просели).
4. Темп ×1.3 по умолчанию; участки медленнее — по согласованию.
5. Технические субтитры: словарь (`replace`: селлеры, WB, Ozon, MVP, цифры), цензура звёздочкой — мат (АХ*ЕЛИ) и запрещённые слова (р*бли, бесплатн*, ст*ит, подп*ска, д*ньги, зар*боток) — в звуке мат остаётся; до 2 строк, ~26 знаков в строке, шрифт ~72 px, блок ≥1.2 с, ≤3 слов/с; низ в safe-zone (Y ≤ 1530, X 60–890).
6. **Черновик рендерить лёгким**: 720p (`scale=0.6667`) и, где можно, из прокси. 4K — только чистовик.
7. Самопроверка до отправки: синхрон по каждому фрагменту (лог base) и после Remotion (`sync_fix`, должно быть ≤10 мс); громкость −14 LUFS, пик ≤ −1 дБ; лист склеек (взгляд, прыжки); повторная расшифровка готового ролика и сверка с субтитрами; субагент-ревьюер по этому чек-листу, не видевший процесса.
8. Отдать: превью ≤30 МБ через `SendUserFile` (сжать `-b:v ~3.3M` для 60 с), список склеек с таймкодами, вопросы. Правки Влада по таймкодам → точечно в план → новый черновик.

### Этап 3. Монтажный лист и материалы → **утверждение №2**
В `монтажный_лист.md` по каждой фразе итогового текста: время, раскладка (лицо / сплит «экран сверху, лицо снизу» / лицо в окне поверх графики / вставка на весь экран / мультсцена), графика (блок Reel.tsx или HyperFrames, якорь-слово), вставка, SFX, музыка (настроение, подъём/стоп), переход. Ритм: новый визуал каждые 2–3 с, лицо 40–60% времени, хук виден с кадра 0.
Список материалов с номерами:
- **М** — от Влада (скрины кабинета WB/Ozon с цифрами, фото из прошлого, архивное видео, продукты). Предлагай сам, где реальные доказательства усилят кадр.
- **С** — сток (что, 3–5 поисковых запросов, 2–3 ссылки-кандидата). Источники: Pixabay, Mixkit (видео, музыка, SFX), YouTube Audio Library (не «YouTube only»), Kenney/Freesound CC0. Не брать: BBC SFX, Uppbeat Free, Bensound, CC BY-NC/ND.
- **Г** — делаешь кодом.
- **Музыка** — 1–2 трека с настроением и кандидатами.
Влад вычёркивает и распределяет: сам ищет или ты через встроенный браузер (скачивание — только с его «да»; массово скриптами с Pixabay/Mixkit не качать — запрещено условиями). Файлы — в `materials/` с номером в имени. Проверь: разрешение, ориентацию, лицензию (ссылку сохрани в `materials/_licenses.md`), чувствительные данные на скринах (ФИО, номера, суммы — размыть).

### Этап 4. Черновик 2 — полный монтаж → **утверждение №3**
1. Вставки: сток — обрезка, 9:16 (кроп или размытый фон), цвет под LUT; фото — медленное движение, рамка; скрины — 3D-наклон, наезд к цифре, обводка маркером, размытие чувствительного.
2. Графика/моушн по листу (Reel.tsx, Cartoon.tsx, блоки HyperFrames), раскладки.
3. Субтитры в финальном стиле, не перекрываются графикой.
4. Звук: музыка с дакингом под голос (−18…−22 LU под речью), подъёмы/стопы на акцентах, SFX на появления/переходы, итог −14 LUFS.
5. Проверка: как в этапе 2 + перекрытия графики с лицом/субтитрами, безопасные зоны Instagram (низ, правый край), орфография, звёздочки, субагент-ревью. Черновик 720p → правки → точечная пересборка.

### Этап 5. Чистовик
Рендер 1080×1920 из 4K-оригинала (не из прокси), высокий битрейт; финальная проверка + покадровая сверка с утверждённым черновиком; упаковка: mp4, обложка (кадр хука), текст поста/хэштеги/закреп, SRT; всё — в `output/`, решения — в `status.md`.

## 5. Экономия (Влад следит за лимитами)
- Один ролик = один чат. Контекст — из проектных документов и `status.md`, не из длинной переписки.
- Не читать в контекст большие файлы (расшифровки целиком, пословный json, каталоги) — печатай выжимки (`grep`, срезы, `python -c`).
- Картинки только нужные: один лист дублей, один лист склеек, 1–2 контрольных кадра. Без скриншотов экрана.
- Черновики — лёгкие; 4K один раз. Ожидание задания — один `sleep`.
- Не перестраивать конвейер без нужды: если чего-то не хватает — минимальная доработка, записать в `Монтаж — правила и конвейер.md`.

## 6. Стиль (дизайн-код «Визуальный язык MAOS»)
Oswald 700 капс, белый + чёрная обводка/тень, акцент — красный бокс `#e60f13` (тень `#b60b0e`), цифры крупные красные; плашка-титр «Влад Угольников» обычным регистром; чип серии красный сверху; UI-шрифт Golos Text. Спека: `Продакшн/Заметки/Визуальный язык и пайплайн.md`. Влад хочет субтитры мельче и дольше на экране; уровень графики — как в референсах (новый визуал каждые 2–3 с), а не «лицо + плашки».

## 7. Съёмка (напоминать Владу перед пересъёмкой)
Кадр по грудь (лицо ≥ ~500 px по ширине 4K), HEVC вместо ProRes, звук PCM 48 кГц (DJI Mic Mini через ресивер), дубли ≤3–5 мин, хлопок в кадре в начале дубля, смотреть в камеру до конца фразы, «хороший дубль» после удачного, оставить место в кадре, если в листе сплит/окно.

- **Планы.** Держи в `status.md` явную строку «база чистовика: plans/X.json, графика: plans/Y_gfx.json». Перед удалением версий перенеси именно эти планы + `*_words.json`, `*_transcript.txt` в `Ролики/…/plans/`. Удалять версии — только после сверки со `status.md` (28.09 так потерян базовый план чистовика Манифеста).
