## 1. Формат v3 (под текущий ресурс)

Скорректирован под реальность: тревел без команды, приоритет — регулярность и смысл, а не перфекционизм картинки.

- **Ядро:** talking head под сценарий + B-roll сверху + моушн-графика. Сердце ролика — сценарий.
- **Картинка:** «чисто и по делу», без зацикливания на цвете/ракурсах.
- **Ритм:** старт 2–3/нед, разгон до 4–5 по мере отладки сборки. Ограничитель — сборка (на стороне Клода), а не съёмка.
- **Площадки:** Instagram (охват) + Telegram (аккумуляция) — основа. YouTube Shorts — автопостинг. VK/TikTok/MAX — только бесплатный кросспостинг.
- **Приоритет 3–6 мес:** рост аудитории **селлеров**, которые доверяют → будущие клиенты MAOS. Не консалтинг/менторство, не рост ради роста.

## 2. Рецепт эталона (реверс-инжиниринг IMG_7336)

**Тех:** 4K вертикаль 2160×3840, 30 fps, 49.9 сек. Непрерывный аудио-бэд (музыка под голосом) + закадровый голос.

**Монтаж:** ~33 склейки за 50 сек → средний план **~1.5 сек**, плотно. Соотношение **~70% B-roll / 30% talking head**. Без анимации и «мастерских» склеек — чистый ритмичный монтаж на нарезке.

## 3. Пайплайн монтажа

Каждый элемент эталона = переиспользуемый блок.

0. **Сценарий + шот-лист** — текст пишем, размечаю: TH / B-roll / красный акцент / чёрный экран / цифра. *(без компа)*
1. **Съёмка по правилам** — TH дубли без остановки камеры (петличка, ровный свет), B-roll с осмысленными именами (`broll_склад_упаковка.mov`). *(Влад)*
2. **Препроцессинг (скрипты)** — нормализация звука, чистка шума, транскрипт с выравниванием по словам для караоке-субтитров, авто-обрезка пауз. *(Клод, на Mac)*
3. **Черновой монтаж по тексту → JSON-таймлайн** — выбор дублей, B-roll под фразы, ритм ~1.5 с/план, акценты, чёрные экраны. *(Клод)*
4. **Сборка в Remotion** из библиотеки компонентов (дизайн-система субтитров + графика) + музыка с дакингом. *(Клод, на Mac)*
5. **Цвет (LUT) → рендер → правки по превью.** *(Клод)*

Инженерная кухня пайплайна (Remotion, скрипты) — в отдельном чате «Пайплайн сборки видео с Remotion».

## 4. Визуальный язык

### 4.1. Субтитры — СОГЛАСОВАНО ✓
- **Шрифт:** превью — Oswald; в проде подобрать точный (Druk / TT Firs Neue / что было у монтажёра). *(TODO: зафиксировать)*
- **Начертание:** КАПС, вес 700, лёгкий letter-spacing.
- **Цвет:** белый + чёрная обводка/тень (читаемость на любом фоне).
- **Акцент:** красный бокс на ключевом слове (#e60f13), белый текст, лёгкий «отскок».
- **Цифры:** крупные красные, моноширинные, вписаны в кадр (авто-ужатие по ширине).
- **«ДЕНЬ N»:** красный чип сверху — якорь сериальности.
- **Плашка-титр:** имя обычным регистром с заглавными («Влад Угольников»), компактно.
- **Появление:** пословно, ~100 мс/слово, scale 0.85→1 + fade.

### 4.2. Моушн-графика — набор
**База (делаем первой):** субтитры · крупная цифра (одометр, вписан в кадр) · чёрный экран/силуэт · плашка-титр.
**Данные:** бар-чарт (анимированная шкала + пропорциональные столбцы) · было/стало (резкий контраст + бейдж дельты).
**Ситуативные:** новостная строка (горящие темы) · тег локации (тревел как фишка).

### 4.3. 3D — направление сохранено, НЕ целевое сейчас
- Демо: 3D-бокс продукта (обложка — **плейсхолдер**, сгенерирована для примера; в проде нужен реальный рендер/арт продукта) + 3D-сеть AI-агентов MAOS.
- Технически рендерится в видео через Remotion + Three.js (@remotion/three).
- Вернуться, когда будут реальные ассеты продукта и появится приоритет.
