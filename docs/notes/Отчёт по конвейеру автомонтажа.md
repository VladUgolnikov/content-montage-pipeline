## Как работает

Конфиг `config.json` держит стиль субтитров, безопасные зоны, параметры наезда и реза.
1. **Звук:** `denoise.sh in.mov out.wav` — чистит фон, ровняет громкость.
2. **Рез:** `autocut.sh raw.mov cut.mp4` — убирает паузы/дубли по тишине (ASR не нужен).
3. **Наезд:** `python3 pushin.py clip.mov` → выдаёт zoompan-выражение к центру лица.
4. **Субтитры:** транскрипт `[{start,end,text,style}]` → `python3 subtitles.py t.json -o subs.ass` → прожиг через ffmpeg `ass=`.
5. **Сборка:** concat сегментов + `ass=subs.ass` + аудио.

Стили субтитров: `Main` (белый), `Box` (красный бокс на акценте), `Num` (крупная красная цифра). Безопасная зона: `margin_v=420` — текст выше нижней подписи, правую колонку кнопок не занимает.

## Пробелы для монтажа готовых видео ⚠️

1. **⛔ GigaAM — нет весов модели (главный пробел).** В зипе `GigaAM-main.zip` только исходники; веса (onnx, RU, пословно 40мс) лежат на HuggingFace, а он заблокирован и в контейнере, и на Mac (один прокси). Без ASR нет **автоматического пословного распознавания** → субтитры и «рез по словам» пока требуют ручного транскрипта. **Нужно:** скачать веса GigaAM v3 (onnx) на своей обычной сети и положить в `pipeline/models/gigaam/`.
2. **DeepFilterNet3 — модель есть, раннера нет.** onnx (enc/erb_dec/df_dec) в `models/dfn3/`, но для запуска нужен отдельный onnx-DSP-раннер. Сейчас работает fallback ffmpeg (слабее: ~20 дБ против 41 дБ у DFN). Доработка — отдельная задача.
3. **Наезды — по первому кадру сегмента.** Для движущегося лица нужен покадровый трекинг (сейчас достаточно для статичного talking head).
4. **Синхронизация губ (DFN-флаг 27мс)** — актуальна только при включении DFN.

## Что даёт это уже сейчас
Полу-автоматический монтаж: чистим звук → режем паузы → наезды → наши субтитры по транскрипту → сборка. Не хватает только автоматического ASR (GigaAM), чтобы субтитры и рез считались из речи без ручного тайминга.
