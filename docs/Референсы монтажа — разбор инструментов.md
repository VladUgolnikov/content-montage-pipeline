# Референсы монтажа — разбор инструментов (26.09.2026)

Источник: 1 YouTube + 9 Reels, собраны через Apify.

## По роликам
1. **Jason Cooperson (YouTube) — «One-shot Claude video editor».** Claude монтирует ролик целиком по одному промпту (2 ч 42 мин, 740k контекста), управляя Premiere/DaVinci через MCP. Главное: «вкус» живёт не в модели, а в **библиотеке пресетов**, которую собрал человек-монтажёр: цвет, анимированный текст, наезды, всплывающая графика, свет/тёмные фоны, правила когда какую графику ставить, правила звуков. Конвейер: WhisperX → черновой рез → **петля ревью субагентами** → звук → цвет → навыки «план графики → сборка графики → ревью» → план SFX → музыка → ревью человека → рендер. Графика — HyperFrames (HeyGen, open-source).
2. **@not_morozov — Opus + код-анимация.** Иллюстрированные «мультяшные» сцены (тетрадь, девочка в окне, росток, муравей), всё заскриптовано кодом, легко править. Субтитры — маленькая чёрная плашка сверху. Вывод: сцены-иллюстрации вместо B-roll; генерация от 20 мин до часов, токены ест.
3. **@rage.s_ — Kant Tools (плагин Premiere/AE).** Каждое слово — отдельный визуал: одно слово крупно по центру, наклонённые 3D-скрины интерфейса, стикеры/эмодзи, жёлтые пятна, виньетка, кадр не стоит ни секунды. 88k просмотров.
4. **@visually.animations — «один промпт» рекламный ролик Upwork.** 3D-мокапы устройств (телефон, монитор, планшет), брендовый зелёный свет, чистые продуктовые сцены. Вывод: формат для продуктовых демо.
5. **@igorzuevich — HyperFrames + ChatGPT.** Говорящая голова + **сплит** (сверху UI/экран, снизу лицо), карточки «ШАГ 1…4» на тёмных панелях, **караоке-субтитры** мелкие с подсветкой текущего слова, CTA «2212 в комментарии» крупной жёлтой 3D-надписью. Процесс: план анимации за 2 мин → утвердить → экспорт через 6–8 мин.
6. **@danyatalented — Motion (motion.so) как MCP-коннектор к Claude.** Снято телефоном с экрана, простые капс-субтитры. 62k просмотров при минимальном продакшне — работает тема.
7. **@paul.molyanov — Remotion + Opus.** Каждая сцена в своём стиле: газетный коллаж, матрица, неон, пиксель-арт, синтвейв, 3D-кот, sci-fi HUD, меловая доска. Закадровый голос, лица нет. Доказывает: Remotion это умеет, разница — в дизайне каждой сцены.
8. **@softgirlnocode — скетч + open-source проект (HyperFrames + ElevenLabs).** Лицо в маленьком окне поверх полноэкранных тёмных графических панелей с зелёным акцентом. 155k просмотров. Раскладка «графика во весь экран + лицо картинкой-в-картинке».
9. **@jayantcreates.ai — программные рилсы.** Кинетическая типографика на кремовом фоне, зачёркивания, счётчики, растущий график, окна-карточки, анимированный CTA «Comment». Минимум цветов — максимум движения.
10. **@raph__ai — JEV + Claude (реклама).** Лицо + записи экрана + простые субтитры. Формат «вау-хук + демонстрация».

## Почему у них выглядит круто
- **Новый визуал каждые 1–3 с.** Лицо в кадре 30–50% времени, остальное — графика, скрины, иллюстрации.
- **Библиотека готовых пресетов** (или HyperFrames/Kant) вместо графики с нуля на каждый ролик.
- **Раскладки**, а не только «лицо + плашки»: сплит экран/лицо, лицо в окне поверх графики, полноэкранная сцена.
- **Субтитры мельче**: караоке с подсветкой слова или маленькая плашка; либо одно крупное слово как дизайн-элемент.
- **Музыка и звуковой дизайн всегда** (все ролики −14 LUFS, музыкальная подложка).
- **Процесс: план графики → утверждение → сборка → ревью-петля**, а не сразу рендер.

## Что делаем у себя
1. **Библиотека пресетов** один раз: 3 раскладки (лицо / сплит UI+лицо / лицо в окне поверх графики), кинетическая типографика, счётчики и графики, 3D-наклон скринов, мокапы устройств, переходы, 2 стиля субтитров. HyperFrames — источник блоков, Remotion — движок.
2. К каждому сценарию — **план визуала по фразам** (бит каждые 2–3 с), утверждение текстом до монтажа.
3. **Банк музыки и SFX** + правила звука.
4. Правки — только на **черновиках 720p по прокси**; финал из 4K один раз.
5. Петля **ревью субагентом** по чек-листу перед показом.

## Инструменты
- **HyperFrames (HeyGen, Apache 2.0, бесплатно)** — лежит в `pipeline/assets/hyperframes/`: 165 готовых блоков (графики, счётчики, карусели, переходы, рукописные `hw-*`, чаты, код, flowchart), 224 компонента (30+ стилей субтитров: караоке-пилюля, kinetic slam, emoji-pop, неон; counters, checklists, before/after, device-frame, callout-circle, marker-highlight…), 3 темы, 21 навык для агента (в т.ч. `talking-head-recut`, `embedded-captions`, `motion-graphics`). CLI ставится `bridge/setup_hyperframes.sh` вне iCloud: `~/Library/Application Support/MAOS-bridge/hyperframes`, ffmpeg/ffprobe — `MAOS-bridge/bin` (из Remotion). Рендер через headless Chrome.
- **Motion (motion.so)** — сторонний, платный (от $5).
- **Remotion** — движок конвейера (проверено: мультяшные сцены «бумажная аппликация»).

## Открытые библиотеки для монтажа (проверено 26.09)
**Музыка:** Pixabay Music (без указания автора; возможны претензии Content ID — хранить ссылку на трек для оспаривания), Mixkit (свободно для соцсетей, массово качать нельзя), YouTube Audio Library (только треки с лицензией «YouTube Audio Library», не «YouTube only»), Chosic раздел CC0. Запас: Incompetech (CC BY — нужна подпись), FMA только CC0/CC BY.
**Звуки:** Kenney (CC0, ZIP-паки: Interface, UI, Impact, Digital, Casino), Freesound с фильтром CC0 (API-ключ бесплатный), Sonniss GDC Bundle (роялти-фри, монетизация разрешена), Pixabay/Mixkit SFX.
**Шрифты (OFL, кириллица):** жирные — Montserrat, Unbounded, Rubik, Golos Text, Onest, Manrope, Inter; узкие вместо Druk — Oswald, Alumni Sans, Sofia Sans Extra Condensed, Roboto Condensed; акцент — Russo One, Dela Gothic One, Tektur, Days One; рукописные — Caveat, Marck Script, Bad Script, Neucha, Pangolin; PT Sans/Narrow. Качаются скриптом `bridge/fetch_assets.py` из github google/fonts.
**Не брать:** BBC Sound Effects (некоммерческая), Uppbeat Free (3 трека, только личное), Bensound Free (атрибуция, риск Content ID), любые CC BY-NC / CC BY-ND, Bebas Neue и Anton (нет кириллицы).
