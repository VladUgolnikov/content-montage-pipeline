## Правила порядка (с 28.09.2026)

1. **Одна копия.** Файл живёт в одном месте. Чистовик — только в `Ролики/…/output/`; в `pipeline` его копий нет. Исходники — только на T7.
2. **Черновики.** Предыдущая версия черновика удаляется, как только утверждена следующая. В `Ролики/…/output/` хранятся только: чистовик, опубликованные тестовые варианты, обложка, SRT, текст поста.
3. **Рабочие файлы ролика в `pipeline`** (базы, драфты, листы проверки, планы старых версий, props): живут, пока идёт работа. Через **5 дней после публикации** удаляются; финальные планы и расшифровка (`*_words.json`, `*_transcript.txt`) переезжают в `Ролики/…/plans/`.
4. **Временное:** `_archive/_in_*` (копии при передаче файлов) — удалять сразу после проверки; `_sync/`, превью, скриншоты-проверки — в конце сессии; логи и итоги моста (`bridge/logs`, `bridge/done`) — старше 3 дней.
5. **Исследования:** сырые выгрузки и бандлы (`*.tar`, `raw/`) — удалять после разбора; видео-референсы храним, пока идёт работа с ними, затем решаем вместе.
6. **Уборка — часть работы:** каждый чат в конце этапа убирает за собой по этим правилам и пишет в `status.md`, что удалено. Раз в неделю — сверка всей папки.
