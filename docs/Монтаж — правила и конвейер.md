## Правила вкуса Влада (26.09, по черновику 2 Манифеста) — соблюдать во всех роликах
- **Меньше эффектов, всё должно успевать читаться.** Блок держится столько, чтобы его можно было прочитать; не ставить эффект на каждую фразу. Быстрые полноэкранные вставки меньше ~1 с — нельзя.
- **Не перекрывать экран ради акцента цифры** — акцент делать шрифтом/типографикой поверх кадра, а не чёрным экраном (исключение, которое он сам попросил: «АХ*ЕЛИ» крупно на чёрном).
- **Раскладки менять редко и плавно.** Не прыгать окно → полный кадр → пол-экрана за несколько секунд; одна раскладка держится на смысловой блок. Лишние кадры-вспышки с лицом между двумя графиками — убирать, переход сразу.
- **Лицо не уезжает вниз и не перекрывается субтитрами.** В сплите лицо остаётся в верхней половине своей зоны, субтитры — не на лице; графика сверху компактнее.
- **Логотипы брендов (WB, Ozon, Яндекс Маркет) — настоящие логотипы**, а не плашки с текстом.
- **Мульт-вставки нравятся** (кувшин «Маржа селлера» с лисами) — делать детально, естественную физику.
- **Звук и музыка согласуются на этапе монтажного листа:** заранее скачать 3–5 вариантов музыки (подложить под голос ролика — отдельный файл на каждый) и доску звуков (по моментам, 2–3 варианта), Влад выбирает до сборки черновика 2. Без выбора — не ставить. «Вжух» на каждую вставку — нельзя.
- Плашка-титр: «Влад Угольников · основатель ZUBRO».

## Синхрон: как мерить и лечить (26.09, главное)
- **Причина «плывущего» звука была не в дрейфе, а в постоянном сдвиге.** У Blackmagic Camera + DJI Mic звук по губам отстаёт на несколько секунд, стабильно по всему файлу: C086 — ~2.95–2.99 с, C095 — **3.761 с** (±5 мс, дрейфа нет). Плюс в индексе MOV звук стоит с пустой правкой (elst): C086 0.423 с, C095 **1.615 с**.
- **Ловушка:** ASR и огибающая считаются по звуку с первого сэмпла (без elst), а рез шёл по таймлайну файла → старые версии резали звук на a_start раньше слов и брали картинку на ~3 с не от той фразы. Из-за этого же в листах дублей «взгляд уходит вниз в конце фразы» — кадр был на 3 с позже слов. С поправкой взгляд в камеру держится.
- **Что делать с каждым новым исходником:**
  1. `bridge/moovinfo.py SRC` (2 с, читает только индекс): частота кадров (плавающая?), `elst` звука → это `a_start`.
  2. `bridge/avsync.py export SRC _sync/X_360.mkv` (≈1–4 мин) → лёгкая копия 360p с исходными таймстемпами; Claude в облаке меряет сдвиг губы/звук (FaceMesh, раскрытие рта против огибающей, окна по 60 с, ±5 с) → `av_offset`. Скрипт замера — `lipsync_cloud.py`/`fine.py` (в облаке, mediapipe 0.10.14). `bridge/lipsync.py` на Маке ненадёжен — не использовать.
  3. В план base/review: `"a_start": …, "av_offset": …`; при плавающей частоте — `"cfr30": true`.
  4. Проверка: экспорт базы тем же `avsync.py` и замер — должно быть |сдвиг| ≤ 35 мс.
- Для `avsync.py export` брать контейнер `.mkv` (mp4 падал на длинных VFR-прокси). `avsync.py ls "/Volumes/T7 Shield"` — список файлов на T7 (обычный device_bash T7 не видит).

## Съёмка и исходники
- iPhone 15 Pro Max + Blackmagic Camera → SSD **T7 Shield**, петличка DJI Mic Mini. Вертикаль 4K, Rec.709, прокси всегда включены.
- C095 (26.09): HEVC, **плавающая частота** (~28.7 fps, 44% кадров по 1/27 с) — монтаж приводит к 30 fps по таймстемпам (`cfr30`). Звук PCM 48 кГц — хорошо.
- Кадр по грудь (лицо ≥ ~500 px по ширине). Исходники с T7 **не копируем**. T7 иногда отваливается — проверять `avsync.py ls`.

## Мост (исполнитель на Маке)
- `pipeline/bridge/runner.py` — исполняет задания из `bridge/jobs/*.json`, только скрипты из белого списка: montage.py, cut.py, bridge/{selftest,diag,lipsync,refs,fetch_assets,avcheck,moovinfo,avsync,clap,media}.py, remotion/sync_fix.py (py); bridge/{setup_remotion,render_remotion,setup_hyperframes,render_hf}.sh (sh). **Сам перезапускается при обновлении runner.py.**
- `bridge/media.py`: `sheet` (лист кадров B-roll), `find`/`fetch` (страницы и файлы стока — Mixkit отдаёт JSON-LD со ссылками на mp3), `clip` (вырезать кусок в h264).
- Запуск после перезагрузки Мака: двойной клик «Запустить мост.command» (окно держать открытым). Автозапуска нет.
- Среды — локально, вне iCloud: `~/Library/Application Support/MAOS-bridge/{venv, node, remotion}`.
- Пути в заданиях — маковские (`/Users/vladislavugolnikov/Desktop/…`), не пути VM (`/sessions/…`).
- Нагрузка: расшифровка 17 мин — ~2 мин; база 65 с из 4K HEVC — ~100 с (с B-roll); Remotion draft с графикой — ~95 с.

## Порядок производства (утверждено 26.09) — подробно в навыке `montazh-rolika`
Идея → сценарий → съёмка → **1. Разбор записи** → **2. Черновик 1: чистое видео** — *утверждение* → **3. Монтажный лист и материалы + музыка и звуки (варианты)** — *утверждение* → **4. Черновик 2: полный монтаж** — *утверждение* → **5. Чистовик**.
- Один ролик = один чат. Папка ролика: `Личный бренд/Ролики/<ГГГГ-ММ-ДД>_<тема>/` — `status.md`, `plans/`, `materials/` (+ `_licenses.md`), `output/`.
- Черновики — 720p (Remotion `draft`), 4K только чистовик. Превью в чат ≤30 МБ (`-b:v 3.3M`); device_commit_files берёт файлы ≤20 МБ — большие копировать на Маке через `cp`.
- Графику можно проверять стоп-кадрами в облаке: `rem/` (Remotion 4.0.529 + headless_shell из /opt/pw-browsers), скрипт `stills.mjs`.

## Рез (montage.py, mode base)
- Поля плана: `a_start`, `av_offset`, `cfr30`, `speed`, `voice_chain`, `colorgrade`, `draft`, `no_lut`; в edl третий элемент — опции куска: `{"mute_from": t}` (обрыв слова, «АХУ…»), `{"min_pause": 0.8}` (не резать паузы внутри куска). B-roll: `broll` с якорями `at_word`/`until_word` (`=слово` — точно, `слово#2` — второе вхождение).
- Цвет Манифеста — вариант B «тёплое кино»: строка `colorgrade` в `pipeline/plans/C095_m1.json` (план чистовика `C095_v3.json` удалён при уборке 28.09 — при нужде вернуть из «Недавно удалённых» iCloud).
- Голос: мягкая цепочка `highpass=f=80,afftdn=nr=7:nf=-50,deesser,equalizer=f=3500:t=q:w=1:g=2,acompressor=threshold=-20dB:ratio=3,loudnorm=I=-14:TP=-1.5:LRA=11`.
- После Remotion (`render_remotion.sh`) — финальный лимитер + loudnorm −14 (музыка+SFX давали +2 dBFS).

## Субтитры (Remotion, Reel.tsx + build_props.py)
- В gfx-плане блок `"subs": {"max_chars": 36, "max_words": 6, "gap": 0.35, "min_dur": 1.2, "size": 72, "orphan_chars": 40}` — кегль 72, ≤2 строки. `nosubs` — где прятать.
- Oswald 700 капс, белые с чёрной обводкой, акцент — красный бокс #e60f13. Низ — Y 1530. Цензура — через `replace` (АХ*ЕЛИ, ст*или, ст*ит…) и в текстах графики («Цена вопроса» вместо «сколько стоит»).

## Техника работы (для Claude)
- Тяжёлое — только через мост. Экран Мака не трогать без необходимости.
- Кириллица на диске в NFD — пути через `grep`. Загрузка на Мак кэшируется по имени — новые версии под уникальным именем в `_archive/_in_…`, затем `cat` поверх, сверка md5 и **сразу удалить `_in_…`**.
- Удаление: в начале сессии запросить право удаления для папки «Личный бренд» (`device_request_delete_permission`; путь передавать в NFD — «й» = «и» + U+0306, иначе ответ «не корень»). В папке работают и другие чаты — перед правкой montage.py/config.json/runner.py сверять md5.
