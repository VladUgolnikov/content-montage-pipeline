# Хуки и удержание — метод (из опыта личного бренда, 28.09.2026)

> Цифры и формулы собраны по нише «селлеры WB/Ozon» (66 залетевших роликов). Для товарного контента формулы нужно пересобрать по своей нише тем же способом — но правила кадра 0 и A/B-процесс переносятся как есть.

## Что показал провал первого ролика
Пробные Reels: 113 просмотров, пропуски 52%, удержание 84% → 58% → 49% на 1/2/3 с, второй обвал на 7–11 с, средний просмотр 7 из 66 с.
- Кадр 0 без хука (лицо + приветствие), цифры только на 3–6 с.
- «О себе» до пользы → обвал.
- Пробные Reels идут только неподписчикам: при пропусках >40% показы глохнут.

## Что видно в данных
- **Эмоция + злодей + цифра в первой фразе.** Нейтральных вступлений почти нет.
- Приветствие первым для холодной ленты не ставят.
- **Хук текстом без голоса работает** — новость текстом на весь кадр набирала 1,4–1,7 млн.
- Лид‑магниты и анти‑советы дают больше всего комментариев.

## Правила кадра 0 (для монтажа)
- Хук‑текст на экране с первого кадра (≤7 слов, цифра или злодей).
- Суть в первой фразе ≤2 с.
- Никакого «о себе» и приветствий до пользы.

## Процесс
1. На каждый сценарий 3–5 хуков из разных формул → выбрать 2–3 → снять/собрать подряд.
2. **A/B через пробные Reels:** одно тело, 2–3 начала. Через 24–48 ч сравнить пропуски, удержание на 3 с, среднее время, отправки. Цель: пропуски <40%, удержание на 3 с >60%.
3. **Мониторинг:** раз в 2 недели Reels ниши через Apify (`bridge/refs.py`, режим `raw`), видео выбросов — режим `dl`, хуки — режим `hooks` (расшифровка первых 15 с GigaAM + кадры 0–3,5 с) → банк хуков.
